# ASAP-3: 8-bit breadboard computer

Welcome to the repository for the ASAP-3 ("**A**lmost as **S**imple **A**s **P**ossible"), an 8-bit CPU inspired by [Ben Eater's design](https://www.youtube.com/watch?v=HyznrdDSSGM&list=PLowKtXNTBypGqImE405J2565dvjafglHU) and based primarily on improvements made by [Fadil-1](https://fadil-1.github.io/blog/8-bit_breadboard_CPU/overview/).
